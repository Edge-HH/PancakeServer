# Pancake Server

> [Pancake](https://github.com/Edge-HH/Pancake) 班级作业看板的集控服务端。

ASP.NET Core 服务端，默认监听 `http://0.0.0.0:5080`，用 SQLite 保存班级、项目、布局、人员和账号数据，附件与背景文件按 SHA-256 存放在 `assets` 目录。服务端与桌面端分仓库、独立版本发布。

## 目录

| 路径 | 说明 |
|---|---|
| `src/Pancake.Server` | 服务端与网页控制台（`wwwroot`） |
| `src/Pancake.Server/BoardAssets` | 网页大屏预览用的字体、图标与示例底图，发布时复制到 `board-assets` |
| `src/Pancake.Shared` | 与桌面端共用的协议、设置清单与 RTF 编解码 |
| `tests/ServerLogic` | 服务端集成测试：临时数据库 + 随机端口 |

> `Pancake.Shared` 与 `BoardAssets` 在桌面端仓库各有一份。修改协议或设置清单时两边需同步修改；协议有不兼容变化时，服务端和桌面端都要发布新版本。

## 下载与部署

在 [Releases](https://github.com/Edge-HH/PancakeServer/releases) 下载对应平台的包：

| 包 | 说明 |
|---|---|
| `PancakeServer-win-x64-*.zip` | Windows，自带运行环境，运行 `Pancake.Server.exe` |
| `PancakeServer-linux-x64-*.tar.gz` / `linux-arm64` | Linux，自带运行环境，运行 `./Pancake.Server` |
| `PancakeServer-portable-*.zip` | 框架依赖，需安装 ASP.NET Core 8 Runtime，运行 `dotnet Pancake.Server.dll` |

首次启动会创建管理员 `admin`，初始密码为 `admin`，部署后应立即修改。可在 `appsettings.json` 或命令行（如 `--Urls http://0.0.0.0:8080`）调整：

| 配置 | 默认值 | 说明 |
|---|---|---|
| `Urls` | `http://0.0.0.0:5080` | 监听地址 |
| `ConnectionStrings:Pancake` | `Data Source=pancake.db` | SQLite 数据库 |
| `Pancake:AssetsPath` | `assets` | 附件与背景文件目录（相对内容根目录） |
| `Pancake:MaxAssetMegabytes` | `200` | 单个文件上限，超出的背景视频保留各设备本机文件 |

旧数据库启动时会自动补齐新表和新列，无需手动迁移；升级时保留 `pancake.db*` 与 `assets` 目录，覆盖其余文件即可。公开短码只适合非敏感的只读作业，不能代替老师登录凭据。

## 功能

### 完整同步

- **项目**：设备先保存到本机，再按内容哈希判断是否需要上传；内容没变时不产生新修订，历史里不会堆满相同快照。本地删除会通知服务器（服务器保留最后一份内容，可在网页恢复），网页删除后设备也会移除本地项目。
- **附件**：图片附件上传为 `asset:哈希.扩展名` 引用，其他设备下载到自己的项目目录；任何附件下载失败都会放弃本次替换，保留本地版本等下一轮。
- **冲突**：两处同时修改同一项目时，设备采用服务器版本，并把本机内容另存为“本机副本”上传，两边的修改都不会丢。正在编辑的项目不会被替换，编辑结束后再处理。
- **班级布局**：布局模式、分屏比例、组件位置、网格、磁贴字体、控制窗、背景（含图片与视频）、主题与天气城市在同一班级的大屏之间同步；麦克风、锁定、备份、补全和更新等本机设置不上传。按屏幕尺寸自动计算的组件位置不参与同步，尺寸不同的大屏不会互相覆盖。每个班级可选“双向同步 / 网页统一下发 / 不同步”，并保留 30 个历史版本、可回滚、可复制到其他班级。
- **实时**：设备通过 WebSocket 接收项目、布局、公告变化和远程指令，断线后自动退避重连，另有 3 分钟一次的兜底同步；设备会上报版本、待上传数量、最近错误和当前项目。

### 网页控制台

服务端根路径提供网页端（浅色/深色主题，适配手机）：

- **公开查看**：输入班级短码（或打开 `/?code=短码`、`/#/c/短码`）只读查看作业、图片、重要公告和今日值日，设备同步后实时刷新。
- **概览**：今日各班作业布置进度（一键“布置”）、我的分工、设备同步异常提醒、学生与公告统计、最近更新与动态。
- **作业**：浏览、搜索、历史版本与恢复；**网页直接新建项目**（沿用最近项目的科目布局）和**编辑作业**——修改科目、颜色、作业文字和上传图片，磁贴位置、笔迹和未改动作业的富文本格式原样保留，保存后大屏实时更新。
- **班级**：项目 / 布局 / 人员 / 值日 / 公告 / 设备 / 设置七个标签页。
  - 布局：按最近项目的磁贴画出示意图，可调整布局模式、分屏比例、主题、色系、网格、字号与控制窗位置并下发；设置同步策略、查看与回滚历史、复制到其他班级。
  - 人员：为老师分配**班主任 / 科任老师 / 助教**和负责科目（科任老师在网页上只能编辑自己负责的科目，服务端同样校验）；维护学生名单，支持从表格粘贴批量导入。
  - 值日：按星期固定安排，或按小组轮换（每个值日日或每周换组，可按名单小组一键生成或平均分组），预览本周值日；今日值日显示在大屏与公开页。
  - 公告：普通 / 重要 / 紧急三级，可置顶、定时开始和结束；重要、紧急和置顶公告显示在大屏顶部。顶部“公告”页可一次发给多个班级。
  - 设备：在线状态、版本、最近同步、待上传与错误；可远程触发同步或在大屏上弹出消息，重命名与吊销。
- **账号**（管理员）、**操作日志**（管理员）、**设置**（修改密码、主题、服务器状态、在线下载数据库备份）。

同一账号和来源连续输错 5 次密码会被锁定 10 分钟。浏览器的 `<img>` 和 WebSocket 无法附带请求头，登录令牌通过 `access_token` 查询参数传入；上传的非图片/视频文件一律以下载方式返回，避免在本站执行脚本。

### Pancake 客户端

「设置 → 集控」输入服务器地址和配对码即可连接；换到另一个班级时会清空旧的修订记录，全部项目按新项目上传。设置页可单独关闭“同步班级布局”和“在看板上显示公告与今日值日”。连接后控制窗出现“班级”入口，显示连接状态、今日值日、班级公告和全部项目的同步情况，可立即同步或在看板上打开任一项目；分屏模式下班务条放在时钟区上方，不遮挡作业磁贴，点按即可收起。

## 构建与测试

需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。

```powershell
dotnet run --project .\src\Pancake.Server\Pancake.Server.csproj        # 本地启动
dotnet run --project .\tests\ServerLogic\ServerLogic.csproj           # 服务端集成测试
```

桌面端同步服务与真实服务端的端到端测试（`SyncLogic`）留在桌面端仓库，因为它直接编译桌面端源码。

## 发布

版本号只由本仓库的 tag 决定，与桌面端互不影响：

```powershell
git tag v1.2.0
git push origin v1.2.0
```

推送 `v*.*.*` tag 后，「📦 构建与发布」工作流先运行集成测试，再发布 win-x64、linux-x64、linux-arm64（自带运行环境）与 portable（框架依赖）四个包并创建 GitHub Release。也可在 Actions 页面手动运行，只生成产物不创建 Release。推送到 `main` 与 PR 会运行「🧪 测试」。
