## Agent skills

### Issue tracker

Issues 存放在 GitHub Issues（Edge-HH/PancakeServer），通过 `gh` CLI 操作。See `docs/agents/issue-tracker.md`.

### Triage labels

使用默认的五个 triage labels：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：repo root 下一个 `GLOSSARY.md` + `docs/adr/`。See `docs/agents/domain.md`.
